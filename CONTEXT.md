# Crew

Crew installs and manages AI agents across supported coding harnesses.

## Language

**Harness**:
A supported AI coding environment where Crew can install, update, list, and remove Crew agents.
_Avoid_: Agent, tool, platform

**Agent**:
A named AI role that Crew renders and installs into one or more harnesses.
_Avoid_: Persona, role file

**Agent type**:
The interaction role of an agent: main agents face users, worker agents are delegated, and general agents can do either.
_Avoid_: Primary, subagent, all

**Crew**:
The complete set of named AI agents managed by the CLI.
_Avoid_: Agent collection, persona set
